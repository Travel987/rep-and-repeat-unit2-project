# Rep & Repeat Presentation Outline

## 1. Introduction
- My name is Briana Powers.
- Rep & Repeat is a full-stack workout tracking application.
- The goal of the app is to make workout logging simple, motivating, and interactive.

## 2. Problem and Purpose
- Workout information can become scattered across notes, apps, and spreadsheets.
- Rep & Repeat gives users one place to record workouts, exercises, duration, weight, and mood.
- The app also adds music and visual motivation to make the workout experience more engaging.

## 3. Technologies Used

### Front End
- React
- Vite
- React Router
- JavaScript
- HTML
- CSS
- Fetch API

### Back End
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL

## 4. Main Features
- User registration and login
- Logout functionality
- Home dashboard
- Workout creation
- Exercise tracking
- Mood Before and Mood After tracking
- Workout history
- Edit existing workouts
- Delete workouts
- Workout statistics
- Responsive navigation
- Exercise GIF demonstrations
- Workout music previews
- Search and filtering
- RESTful CRUD communication between React and Spring Boot

## 5. Application Demonstration
1. Register or log in.
2. Show the Home dashboard.
3. Select a Mood Before.
4. Start a workout.
5. Enter workout information.
6. Add exercises with sets, reps, and weight.
7. Select a Mood After.
8. Save the workout.
9. Open History to show the saved workout.
10. Demonstrate editing and deleting a workout.
11. Show the Music page.
12. Show the About page.

## 6. Full-Stack Architecture
- React handles the user interface.
- Spring Boot provides REST API endpoints.
- MySQL stores workout and user data.
- Fetch requests connect the React front end to the Spring Boot back end.
- JPA and Hibernate handle database persistence.

## 7. Challenges and Problem Solving

- Managing application state across different views.
- Creating responsive layouts for different screen sizes.
- Debugging API, validation, and styling issues.
